FORMAT REFERENCE

1 · DATE (1st token)

18Day only — next occurrence of the 18th (this month, or next if already passed)
1807DDMM — 18th July, this year (or next year if already passed)
180726DDMMYY — 18th July 2026
18/07 or 18-07 or 18.07DD/MM, current or next year
18/07/2026DD/MM/YYYY, full date
18jul or 18-jul-2026Day + 3-letter month, with optional year
today / tomorrowRelative day keywords
monday … sundayNext occurrence of that weekday

2 · TIME (2nd token)

10Hour only, 24h clock (10 → 10:00)
1030HHMM, 24h clock
10:30H:MM, 24h clock
10pm / 1030am12h clock with am/pm suffix (space before am/pm is OK too)
noon / midnightKeyword shortcuts

⚡ RELATIVE SHORTCUT (replaces DATE + TIME, 1 token)

+30m30 minutes from now
+2h2 hours from now
+1d1 day from now, same time
+1w1 week from now, same time

When used, the TIME field is filled automatically — the very next token starts your message.

3 · MESSAGE (3rd token onward)

Everything after date + time is the message. Add #tag anywhere in it to tag the reminder — tags become clickable filters in the list below.

REPEAT

Once date + time are valid, choose Once / Daily / Weekly / Monthly below the input. Recurring reminders reschedule themselves automatically each time they fire instead of disappearing.
